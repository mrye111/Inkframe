# Inkframe

> Windows 桌面录屏软件（代号 ScreenRecorder）

一款运行于 Windows 10 / 11 的桌面录屏应用，目标是以 Apple 式克制、液态玻璃（Liquid Glass）空间层级的视觉语言，提供简单、高效、稳定的屏幕录制体验。

## 技术栈

| 项 | 选型 |
|---|---|
| 平台 | Windows 10 / Windows 11 |
| 语言 | C# |
| UI 框架 | WPF |
| 架构模式 | MVVM |
| 交付形式 | Windows `.exe` 桌面应用 |

## V1.0 核心能力

- 全屏 / 指定窗口 / 自定义区域录制
- 系统声音 + 麦克风录制
- 多帧率、多画质配置，MP4 输出
- 暂停 / 继续录制
- 全局快捷键
- 录制状态悬浮窗
- 录制历史管理

## 仓库约定

- 需求文档与 UI/UX 设计规范为内部文档，已通过 `.gitignore` 排除，**不会上传至远程仓库**。
- 本地录制产物（`recordings/`、`*.mp4`）不入库。
